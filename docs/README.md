# Documentation

This directory contains the maintained documentation for CTRLZer0 libobjc2.

## Current documentation

- `ARCHITECTURE.md` — runtime layout, subsystem boundaries and build model.
- `CI.md` — per-commit CI, nightly builds and versioned release automation.
- `archive/upstream/` — preserved historical documentation inherited from the
  GNUstep / Microsoft libobjc2 lineage.

Project-wide release history is maintained in the root `CHANGELOG.md`.
Build and quick-start information remains in the root `README.md`.

## Archive policy

Historical upstream material is preserved for provenance and reference, but it
is not treated as current project guidance. Files in `archive/upstream/` should
not be edited to describe CTRLZer0 behavior.

New maintained documentation belongs directly under `docs/` or a focused
subdirectory of it rather than in the repository root.
